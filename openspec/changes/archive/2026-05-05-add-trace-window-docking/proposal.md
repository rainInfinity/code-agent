## Why

Trace 窗口目前只能作为独立浮动窗口使用。调试 Agent 长链路输出时，用户经常需要同时观察主聊天和 Trace，手动摆放两个窗口会打断排查节奏，也容易在主窗口移动、最大化或恢复后失去并排关系。

## What Changes

- 为 Trace 窗口新增贴靠模式，支持在独立窗口、贴靠主窗口左侧、贴靠主窗口右侧之间切换。
- 贴靠时 Trace 跟随主窗口位置和尺寸变化，高度与主窗口保持一致，宽度可由用户拖拽调整并受最小/最大宽度限制。
- 主窗口最大化时，Trace 贴靠到主窗口内侧左边或右边，并在贴靠期间保持置顶，确保 Trace 不被最大化主窗口遮挡。
- 主窗口最小化时，Trace 一起隐藏或最小化；主窗口恢复时，Trace 重新按原贴靠侧和宽度贴靠。
- 贴靠模式下禁用 Trace 最大化按钮；用户拖拽 Trace 标题栏时退出贴靠，Trace 回到独立窗口模式。
- 单独保存贴靠侧和贴靠宽度，不覆盖独立窗口的位置和尺寸状态。
- pin 与贴靠模式不绑定；always-on-top 在贴靠期间强制开启，退出贴靠后恢复进入贴靠前的置顶状态。

## Capabilities

### New Capabilities
- `trace-window-docking`: 约束 Trace 窗口独立/贴靠模式切换、主窗口跟随、贴靠宽度保存、最大化/最小化联动，以及贴靠期间的置顶语义。

### Modified Capabilities
- 无。

## Impact

- 影响 Tauri 窗口管理：Trace 窗口创建、主窗口和 Trace 窗口 move/resize/minimize/restore 事件处理、窗口几何计算、always-on-top 同步。
- 影响前端 IPC：新增或扩展 Trace 贴靠模式、贴靠侧、贴靠宽度、退出贴靠等命令或事件。
- 影响 Trace 前端组件：标题栏新增贴靠控制入口，贴靠模式下最大化按钮禁用，标题栏拖拽触发退出贴靠。
- 影响状态持久化：新增贴靠专用状态，避免覆盖现有独立窗口位置和尺寸。
- 影响 i18n：新增贴靠相关中文按钮标签、提示和可访问名称。
